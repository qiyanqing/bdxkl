## 通用技术参数

### 图片规格
- **分辨率**：512×768
- **比例**：2:3 竖版
- **DPI**：72
- **格式**：PNG（保留透明通道）

### Midjourney 参数
```
--ar 2:3       # 2:3竖版比例
--q 2         # 高质量
--style expressive  # 表现力强
--chaos 10-20  # 适度随机性
```

### Stable Diffusion 参数
```
Resolution: 512×768
CFG Scale: 7-8
Steps: 30-40
Sampler: DPM++ 2M Karras 或 Euler a
```

---

## 构图要求

### 重点区域（上70%）
- 头部：清晰可见，龙珠风格脸型
- 上半身：完整展示
- 武器：清晰可见
- 服饰：细节丰富

### 次要区域（下30%）
- 腰部/腿部：可被UI遮挡
- 背景：简单渐变

---

## 风格一致性

### 所有角色统一标准
1. **脸部**：龙珠Z/龙珠超风格（Trunks/Gohan型）
2. **发型**：龙珠风格的竖直/上翘头发
3. **眼睛**：龙珠风格的锐利眼神+粗眉毛
4. **肌肉**：龙珠肌肉线条（男性），优雅曲线（女性貂蝉）
5. **轮廓线**：3-4px粗黑色线条
6. **上色**：赛璐璐阴影+高饱和度
7. **姿势**：动态战斗姿势，充满力量感
8. **构图**：头部+上半身+武器占上70%

### 三国特征保留
- 关羽：红脸+长须+青龙偃月刀
- 张飞：虎须环眼+丈八蛇矛+重甲
- 黄忠：白须+弓箭+轻甲
- 赵云：白马银甲+龙胆亮银枪
- 吕布：雉鸡翎+方天画戟+华服
- 貂蝉：粉裙+古琴/扇子+美女发型

## 提示词使用技巧

### 生成多张图片对比
```bash
# 使用 --n 参数一次生成4张
niji 6 [提示词] --n 4 --ar 2:3
```

### 调整随机性
```bash
# 增加随机性（更变化）
--chaos 20

# 减少随机性（更稳定）
--chaos 5
```

### 调整风格强度
```bash
# 更忠实于龙珠风格
--niji 6

# 略微融合其他风格
--niji 5
```

4. 选择最佳效果保存
