# 02 - 战斗系统

## 战斗基础

**战斗形式**：6人战队回合制 + 卡牌形式

**血量系统**：
- 每个角色独立血条
- 角色血量归零时死亡，无法继续行动
- 一方所有角色死亡则战斗失败

**蓝条系统**：
- 每个角色独立蓝条
- 只能通过普攻回复蓝量
- 装备/buff可以提升普攻回蓝量

**卡牌视觉**：
- 静态立绘 + 特效表现
- 立绘、职业标签、血条、蓝条、Buff/Debuff图标

---

## 战斗流程

```
1. 双方12个角色按速度排序，形成行动队列
2. 轮到某角色行动时：
   - 根据职业定位自动选择目标（AI判定）
   - 执行普攻 → 造成伤害 + 回复自身蓝条
   - 蓝条满时自动释放大招 → 消耗全部蓝量
3. 角色血量归零时死亡，从战斗队列移除
4. 一方所有角色死亡，战斗结束
```

---

## 蓝条机制详解

### 回蓝方式

| 方式 | 说明 |
|------|------|
| 普攻回蓝 | 每次普攻回复固定蓝量（如10点） |
| 技能回蓝 | 某些角色的技能可以给全队或特定角色回蓝 |
| 装备/buff | 提升普攻回蓝量 |

### 大招释放
- 蓝条满（如100点）时自动释放大招
- 无需手动操作
- 消耗全部蓝量

## 技能系统

### 基础架构
- **角色自带**：每个角色有基础技能
- **关卡内强化**：解锁技能子效果层级（本关生效）

### 技能子效果系统

每个技能有多个层级，关卡内解锁更高层级效果。

**示例**：

**吕布·无双斩**
- 层级1：造成200%攻击伤害
- 层级2：造成250%攻击伤害 + 20%暴击
- 层级3：造成300%攻击伤害 + 30%暴击 + 眩晕

**诸葛亮·落雷**
- 层级1：对敌方3人造成150%法术伤害
- 层级2：对敌方3人造成180%伤害 + 降低防御
- 层级3：对敌方全体造成200%伤害 + 麻痹1回合

### 技能获取与强化

| 来源 | 获取方式 |
|------|----------|
| 战斗格 | 打赢获得本关临时技能 |
| buff格 | 提升技能子效果层级 |
| 商店格 | 购买技能/技能强化道具 |

## 战斗AI

**完全自动战斗**：
- 自动普攻
- 蓝满自动释放大招
- 根据职业定位自动选择目标（无需手动操作）

**AI目标选择逻辑**：
- **坦克**：优先攻击敌方前排，有嘲讽技能时优先使用
- **战士**：优先攻击敌方前排
- **刺客**：检测敌方后排血量最少的目标（法师、射手优先）
- **法师**：检测敌方密集目标释放AOE，优先攻击血量最多的敌人
- **射手**：优先攻击血量最少的敌人（补刀机制）
- **辅助**：检测我方血量最少的目标进行治疗

**敌方AI**：同样逻辑，保证战斗公平性
