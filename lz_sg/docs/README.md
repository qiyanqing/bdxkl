# 龙珠画风三国肉鸽大富翁 - 游戏设计文档

## 项目概述

**游戏定位**：一款融合大富翁地图探索、肉鸽随机性、角色培养的小程序策略RPG游戏。

**核心元素**：
- 龙珠画风（肌肉线条、动态姿态、能量特效）
- 三国题材（全时段穿越混搭）
- 大富翁地图探索（环形转圈）
- 肉鸽随机性（关卡内随机buff/技能）
- 6人战队战斗

**核心循环**：
```
掷骰子前进 → 收集资源（buff/技能/装备）→ 触发战斗 → 阵容变强 → 通关下一关
```

**关卡结构**：
- 多章节闯关制（10个主关卡 + 1个福利关）
- 每关一个独立的大富翁地图
- 地图内肉鸽元素（buff/技能随机）
- 失败仅本关清零，非永久死亡

**通关路线**：
- **实力流**：阵容硬，直接打过去（低星奖励）
- **运气流**：踩到神装/buff，爽飞通关（高星奖励）

## 核心设计原则

1. **三种元素均衡混合**：大富翁探索、肉鸽随机、角色培养同等重要
2. **两条通关路线**：实力流 vs 运气流，都能通关
3. **关卡内临时强化**：本关获取的buff/技能/装备仅本关生效
4. **过关奖励永久**：通关后的星级奖励进入背包，永久保存
5. **探索得高分**：骰子用得越多=探索越深=星级越高
6. **无阵营限制**：删除阵营系统，给玩家更多搭配空间
