# 08 - 卡牌立绘美术规范

**版本**：v1.0
**日期**：2026-02-26
**画风定位**：龙珠风格 + 三国题材

---

## 一、画风定位

### 1.1 核心风格
- **主风格**：龙珠风格（鸟山明画风）
- **特征**：
  - 肌肉线条夸张但合理
  - 动态姿势，充满力量感
  - 线条硬朗，轮廓清晰
  - 色彩饱和度高，视觉冲击力强
  - 眼神犀利，表情坚毅

### 1.2 题材融合
- **三国人物** + **龙珠画风** = 独特的视觉识别度
- 角色保留三国时期的服饰特征（盔甲、兵器、发型）
- 肌肉线条和动态姿势参考龙珠角色

## 二、立绘基础规范

### 2.1 画布尺寸
| 用途 | 尺寸（像素） | 说明 |
|------|-------------|------|
| **卡牌立绘** | 1024×1024 | 正方形画布，便于裁剪适配 |
| **立绘成品** | 约800×1000 | 去除透明背景后的实际内容区域 |
| **技能图标** | 256×256 | 正方形，圆形裁剪 |
| **头像缩略图** | 128×128 | 用于列表、图鉴 |

### 2.2 构图规范
**立绘构图**：
- 采用 **7头身** 比例（龙珠角色典型比例）
- 角色占据画布约70%空间
- 上方留20%空间（用于显示角色名、等级等信息）
- 下方留10%空间（用于血条、蓝条）
- 左右各留5%边距（防止裁剪）

**姿势要求**：
- **动态姿势**：避免呆板站立，选择战斗中的动作瞬间
- **面向角度**：略偏左或略偏右（约15-30度），避免完全正对或完全背对
- **武器展示**：手持武器时，武器要清晰可见
- **手势**：手部要有表现力，避免被身体遮挡

### 2.3 背景处理
- **透明背景**：PNG格式，Alpha通道透明
- **无杂物**：背景完全透明，便于游戏内合成
- **边缘干净**：角色边缘清晰，无白边或锯齿

## 三、职业视觉特征

### 3.1 坦克（Tank）
**视觉关键词**：魁梧、厚重、稳重

| 特征 | 设计要点 |
|------|----------|
| **体型** | 肩宽腰粗，肌肉发达，比其他职业大20% |
| **盔甲** | 厚重铠甲，明显护肩、胸甲 |
| **武器** | 重武器（大刀、重锤、长枪） |
| **站姿** | 扎马步，重心下移，稳如泰山 |
| **表情** | 坚毅、沉稳，眼神坚定 |
| **代表角色** | 张飞、许褚、典韦 |

**典型特征**：
- 张飞：虎须环眼，持丈八蛇矛，肌肉线条夸张
- 许褚：虎背熊腰，持大刀，盔甲厚重
- 典韦：手持双铁戟，表情凶猛

---

### 3.2 战士（Warrior）
**视觉关键词**：均衡、干练、精壮

| 特征 | 设计要点 |
|------|----------|
| **体型** | 匀称肌肉，比例协调，标准7头身 |
| **盔甲** | 轻甲或战袍，便于活动 |
| **武器** | 长兵器（枪、戟、刀） |
| **站姿** | 战斗姿态，随时准备进攻 |
| **表情** | 自信、专注，杀气内敛 |
| **代表角色** | 关羽、赵云、马超 |

**典型特征**：
- 关羽：红脸长须，持青龙偃月刀，威风凛凛
- 赵云：白马银枪，白衣银甲，英气逼人
- 马超：持长枪，姿态飘逸，西凉锦马超

---

### 3.3 刺客（Assassin）
**视觉关键词**：矫健、敏捷、爆发

| 特征 | 设计要点 |
|------|----------|
| **体型** | 精瘦但肌肉线条明显，比其他职业小10% |
| **服饰** | 轻装或夜行衣，便于隐匿和移动 |
| **武器** | 短兵器（双刀、匕首、短戟） |
| **站姿** | 低重心，随时准备冲刺 |
| **表情** | 冷峻、锐利，眼神如刀 |
| **代表角色** | 吕布、张辽、甘宁 |

**典型特征**：
- 吕布：方天画戟，霸气外露，龙珠超级赛亚人般的肌肉线条
- 张辽：持双钩镰刀，沉默寡言的形象
- 甘宁：锦帆贼，持短刀，表情凶狠

---

### 3.4 法师（Mage）
**视觉关键词**：神秘、飘逸、威严

| 特征 | 设计要点 |
|------|----------|
| **体型** | 偏瘦，但气场强大 |
| **服饰** | 长袍、道袍，飘逸感 |
| **道具** | 法杖、羽扇、符咒 |
| **站姿** | 悬浮或坐姿，超脱世俗 |
| **表情** | 智慧、深邃，眼神如炬 |
| **代表角色** | 诸葛亮、周瑜、司马懿 |

**典型特征**：
- 诸葛亮：羽扇纶巾，仙风道骨，手持羽扇
- 周瑜：文雅儒将，持古琴或羽扇
- 司马懿：阴沉深沉，持法杖或书卷

---

### 3.5 射手（Archer）
**视觉关键词**：专注、精准、稳定

| 特征 | 设计要点 |
|------|----------|
| **体型** | 匀称，上肢肌肉发达（拉弓所需） |
| **服饰** | 轻甲，便于瞄准和移动 |
| **武器** | 弓、弩、远程兵器 |
| **站姿** | 侧身瞄准，姿势稳定 |
| **表情** | 专注、冷静，锁定目标 |
| **代表角色** | 黄忠、太史慈、夏侯渊 |

**典型特征**：
- 黄忠：老当益壮，持弓，银须飘飘
- 太史慈：持双短戟或弓，英气逼人
- 夏侯渊：轻装，持弓，快速机动

---

### 3.6 辅助（Support）
**视觉关键词**：温和、优雅、灵动

| 特征 | 设计要点 |
|------|----------|
| **体型** | 匀称，女性角色曲线美 |
| **服饰** | 飘逸长裙、仙气十足 |
| **道具** | 乐器、法器、符咒 |
| **站姿** | 优雅站立或舞动姿势 |
| **表情** | 温柔、慈祥，治愈感 |
| **代表角色** | 貂蝉、大乔、华佗 |

**典型特征**：
- 貂蝉：绝世美人，持古琴或扇子，仙气飘飘
- 大乔：温柔端庄，持法器
- 华佗：仙风道骨，持葫芦或草药

## 四、稀有度视觉区分

### 4.1 边框特效

| 稀有度 | 边框颜色 | 特效描述 |
|--------|----------|----------|
| **金卡** | 金色（#FFD700） | 粒子光环环绕 + 流光边框 + 底部光晕 |
| **紫卡** | 紫色（#9B59B6） | 流光边框 + 闪烁粒子 + 边缘辉光 |
| **蓝卡** | 蓝色（#3498DB） | 简单描边 + 淡淡光晕 |

### 4.2 卡牌底框设计

**技术说明**：边框特效由游戏引擎实现，美术只需提供：
- **立绘主体**：透明背景PNG
- **职业图标**：256×256，透明背景
- **稀有度标记**：角标，128×128

## 五、角色设计要点

### 5.1 三国角色特征保留
- **服饰**：保留三国时期的服饰特征（盔甲样式、官服、战袍）
- **兵器**：使用历史记载或演义中的兵器
- **标志性特征**：
  - 关羽：红脸、长须
  - 张飞：虎须、环眼
  - 诸葛亮：羽扇纶巾
  - 吕布：方天画戟、头上雉鸡翎

### 5.2 龙珠风格化处理
- **肌肉线条**：参考龙珠角色的肌肉表现，夸张但不失真实
- **动态姿势**：参考龙珠战斗中的姿势，充满力量感
- **表情**：参考龙珠角色的眼神和表情，坚毅、专注
- **上色**：饱和度高，明暗对比强烈

### 5.3 性格体现
- 每个角色的立绘要体现其性格和定位
- 勇猛型角色（张飞、许褚）：表情凶猛，姿势霸气
- 智慧型角色（诸葛亮、司马懿）：表情沉稳，气质儒雅
- 优雅型角色（貂蝉、大乔）：姿态优美，气质高贵

## 六、文件格式规范

### 6.1 文件命名
```
角色名_职业_稀有度_用途.png

示例：
GuanYu_Warrior_Gold_Portrait.png      # 关羽_战士_金卡_立绘
ZhangFei_Tank_Purple_Portrait.png     # 张飞_坦克_紫卡_立绘
LuBu_Assassin_Gold_Icon.png           # 吕布_刺客_金卡_头像
```

### 6.2 技术规格
| 规格 | 参数 |
|------|------|
| **格式** | PNG-24（保留透明通道） |
| **色彩模式** | RGB |
| **DPI** | 72（屏幕显示） |
| **最大单文件大小** | 500KB（需压缩优化） |
| **压缩工具** | TinyPNG 或 ImageOptim |

### 6.3 导出设置
- **透明度**：保留Alpha通道
- **元数据**：清除EXIF信息
- **颜色配置**：sRGB IEC61966-2.1

## 八、美术外包流程

### 8.1 交付物检查清单
- [ ] 立绘主体（PNG，透明背景）
- [ ] 头像缩略图（PNG）
- [ ] 技能图标（PNG）
- [ ] 源文件（PSD或AI，保留图层）
- [ ] 预览图（JPG，带背景参考）

### 8.2 质量标准
- **角色识别度**：一眼能认出是哪个三国人物
- **画风统一**：所有角色风格一致，龙珠画风明显
- **职业区分**：六大职业视觉特征清晰
- **稀有度区分**：金/紫/蓝卡有明显的视觉差异
- **细节完整**：无穿模、无错位、无遗漏

### 8.3 修改流程
1. **初稿确认**：线稿或草图确认比例和姿势
2. **上色确认**：确认配色和光影
3. **精修完成**：最终成品确认
4. **技术审核**：检查文件格式、尺寸、透明度
