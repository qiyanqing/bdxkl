# 08 - 卡牌立绘美术规范

**版本**：v1.1
**日期**：2026-02-26
**画风定位**：龙珠风格 + 三国题材

---

## 一、画风定位

### 1.1 核心风格
- **主风格**：龙珠风格（鸟山明画风）
- **特征**：
  - 肌肉线条夸张但合理
  - 动态姿势，充满力量感
  - 线条硬朗，轮廓清晰
  - 色彩饱和度高，视觉冲击力强
  - 眼神犀利，表情坚毅

### 1.2 题材融合
- **三国人物** + **龙珠画风** = 独特的视觉识别度
- 角色保留三国时期的服饰特征（盔甲、兵器、发型）
- 肌肉线条和动态姿势参考龙珠角色

## 二、立绘基础规范

### 2.1 画布尺寸
| 用途 | 尺寸（像素） | 说明 |
|------|-------------|------|
| **卡牌立绘** | 1024×1024 | 正方形画布，便于裁剪适配 |
| **立绘成品** | 约800×1000 | 去除透明背景后的实际内容区域 |
| **技能图标** | 256×256 | 正方形，圆形裁剪 |
| **头像缩略图** | 128×128 | 用于列表、图鉴 |

### 2.2 构图规范
**立绘构图**：
- 采用 **7头身** 比例（龙珠角色典型比例）
- 角色占据画布约70%空间
- 上方留20%空间（用于显示角色名、等级等信息）
- 下方留10%空间（用于血条、蓝条）
- 左右各留5%边距（防止裁剪）

**姿势要求**：
- **动态姿势**：避免呆板站立，选择战斗中的动作瞬间
- **面向角度**：略偏左或略偏右（约15-30度），避免完全正对或完全背对
- **武器展示**：手持武器时，武器要清晰可见
- **手势**：手部要有表现力，避免被身体遮挡

### 2.3 背景处理
- **透明背景**：PNG格式，Alpha通道透明
- **无杂物**：背景完全透明，便于游戏内合成
- **边缘干净**：角色边缘清晰，无白边或锯齿

## 三、经典三国角色形象设计原则

### 3.1 核心原则
**职业是游戏机制标签，不是视觉设计约束**

- 角色形象**忠于历史/演义中的经典形象**
- 职业只影响数值和AI行为，不影响外在形象设计
- 画风上做**龙珠化处理**，但保留角色的经典特征

### 3.2 形象来源参考
| 来源 | 说明 |
|------|------|
| **历史记载** | 《三国志》等史书中的人物描述 |
| **三国演义** | 罗贯中小说中的经典形象 |
| **其他三国游戏** | 三国志、三国无双、真三国无双等 |
| **影视作品** | 94版三国演义、新三国等 |

### 3.3 角色特征保留（示例）

**武将类**：
- **关羽**：红脸、长须、青龙偃月刀、绿袍
- **张飞**：虎须、环眼、丈八蛇矛、黑脸
- **赵云**：白衣银甲、龙胆亮银枪、白马
- **吕布**：方天画戟、头上雉鸡翎、霸气外露

**文官/谋士类**：
- **诸葛亮**：羽扇纶巾、仙风道骨、道袍
- **周瑜**：文雅儒将、羽扇或古琴
- **司马懿**：深沉内敛、官服或道袍

**女性角色**：
- **貂蝉**：绝世美人、古装或舞衣
- **大乔/小乔**：江南美女、飘逸长裙

### 3.4 龙珠画风化处理
在保留经典形象的基础上，做以下龙珠化处理：

| 处理方式 | 说明 |
|----------|------|
| **肌肉线条** | 参考龙珠角色的肌肉表现，夸张但合理 |
| **动态姿势** | 选择战斗中的动作瞬间，充满力量感 |
| **表情** | 眼神犀利、坚毅，参考龙珠角色的表情 |
| **上色** | 高饱和度、明暗对比强烈 |
| **线条** | 硬朗清晰，轮廓分明 |

**重要**：龙珠化是画风处理，不是改变角色经典特征。关羽就是红脸长须持大刀，不会因为画风变化而改变核心形象。

## 四、稀有度视觉区分

### 4.1 边框特效

| 稀有度 | 边框颜色 | 特效描述 |
|--------|----------|----------|
| **金卡** | 金色（#FFD700） | 粒子光环环绕 + 流光边框 + 底部光晕 |
| **紫卡** | 紫色（#9B59B6） | 流光边框 + 闪烁粒子 + 边缘辉光 |
| **蓝卡** | 蓝色（#3498DB） | 简单描边 + 淡淡光晕 |

### 4.2 卡牌底框设计

**技术说明**：边框特效由游戏引擎实现，美术只需提供：
- **立绘主体**：透明背景PNG
- **职业图标**：256×256，透明背景
- **稀有度标记**：角标，128×128

## 五、角色设计要点

### 5.1 三国角色特征保留
- **服饰**：保留三国时期的服饰特征（盔甲样式、官服、战袍）
- **兵器**：使用历史记载或演义中的兵器
- **标志性特征**：
  - 关羽：红脸、长须
  - 张飞：虎须、环眼
  - 诸葛亮：羽扇纶巾
  - 吕布：方天画戟、头上雉鸡翎

### 5.2 龙珠风格化处理
- **肌肉线条**：参考龙珠角色的肌肉表现，夸张但不失真实
- **动态姿势**：参考龙珠战斗中的姿势，充满力量感
- **表情**：参考龙珠角色的眼神和表情，坚毅、专注
- **上色**：饱和度高，明暗对比强烈

### 5.3 性格体现
- 每个角色的立绘要体现其性格和历史形象
- 勇猛型角色（张飞、许褚）：表情凶猛，姿势霸气
- 智慧型角色（诸葛亮、司马懿）：表情沉稳，气质儒雅
- 优雅型角色（貂蝉、大乔）：姿态优美，气质高贵
- 忠义型角色（关羽、赵云）：正气凛然，威风凛凛

## 六、文件格式规范

### 6.1 文件命名
```
角色名_稀有度_用途.png

示例：
GuanYu_Gold_Portrait.png      # 关羽_金卡_立绘
ZhangFei_Purple_Portrait.png   # 张飞_紫卡_立绘
LuBu_Gold_Icon.png             # 吕布_金卡_头像
```

**注意**：文件名不包含职业字段，因为职业是游戏机制标签，不影响角色立绘设计。

### 6.2 技术规格
| 规格 | 参数 |
|------|------|
| **格式** | PNG-24（保留透明通道） |
| **色彩模式** | RGB |
| **DPI** | 72（屏幕显示） |
| **最大单文件大小** | 500KB（需压缩优化） |
| **压缩工具** | TinyPNG 或 ImageOptim |

### 6.3 导出设置
- **透明度**：保留Alpha通道
- **元数据**：清除EXIF信息
- **颜色配置**：sRGB IEC61966-2.1

## 八、美术外包流程

### 8.1 交付物检查清单
- [ ] 立绘主体（PNG，透明背景）
- [ ] 头像缩略图（PNG）
- [ ] 技能图标（PNG）
- [ ] 源文件（PSD或AI，保留图层）
- [ ] 预览图（JPG，带背景参考）

### 8.2 质量标准
- **角色识别度**：一眼能认出是哪个三国人物
- **画风统一**：所有角色风格一致，龙珠画风明显
- **稀有度区分**：金/紫/蓝卡有明显的视觉差异（通过边框特效实现）
- **细节完整**：无穿模、无错位、无遗漏

### 8.3 修改流程
1. **初稿确认**：线稿或草图确认比例和姿势
2. **上色确认**：确认配色和光影
3. **精修完成**：最终成品确认
4. **技术审核**：检查文件格式、尺寸、透明度
