# 角色立绘资源规范

## 目录结构

```
lz_sg/
└── assets/
    └── images/
        └── characters/
            ├── guan_yu.png        # 关羽
            ├── zhang_fei.png      # 张飞
            ├── huang_zhong.png    # 黄忠
            ├── zhao_yun.png       # 赵云
            ├── lu_bu.png          # 吕布
            └── diaochan.png       # 貂蝉
```

## 文件命名规范

### 格式
```
{角色英文ID}.png
```

### 命名对照表

| 角色 | 英文ID | 文件名 |
|------|--------|--------|
| 关羽 | guan_yu | `guan_yu.png` |
| 张飞 | zhang_fei | `zhang_fei.png` |
| 黄忠 | huang_zhong | `huang_zhong.png` |
| 赵云 | zhao_yun | `zhao_yun.png` |
| 吕布 | lu_bu | `lu_bu.png` |
| 貂蝉 | diaochan | `diaochan.png` |

## 图片规格

| 规格 | 要求 |
|------|------|
| 分辨率 | 512×768px (2:3比例) |
| 格式 | PNG-24 (透明背景) |
| 大小 | ≤250KB |
| 背景 | 透明或纯白（后期处理） |

## 构图要求

- **头部**：清晰可见，位于画布上部
- **上半身**：完整展示（占画布70%）
- **武器**：清晰可见
- **下半身**：可被裁剪（占画布30%）

## 使用说明

1. 将生成的立绘图片放到 `assets/images/characters/` 目录
2. 按照命名规范重命名文件
3. 确保图片背景透明或纯白色
4. 图片会自动加载到卡牌中显示
