# 卡牌化 + 独立血条战斗系统设计方案

**日期**：2026-02-26
**设计目标**：将3D建模改为卡牌形式，降低美术成本；将共享血条改为独立血条，增加战斗策略深度

---

## 一、设计背景

### 1.1 问题背景
- 原计划采用3D建模，成本高昂且需要专业技能
- 共享血条系统降低了角色定位的重要性，战斗策略深度不足

### 1.2 设计目标
- **降低美术成本**：从3D建模改为静态立绘+特效
- **增强策略深度**：独立血条+六大职业定位，增加阵容搭配维度
- **适配小程序平台**：卡牌形式更符合小程序性能和用户习惯

---

## 二、卡牌视觉设计

### 2.1 卡牌构成
| 区域 | 内容 |
|------|------|
| **立绘区** | 角色全身/半身静态立绘（龙珠风格，肌肉线条感强） |
| **信息区** | 角色名、等级、稀有度边框、职业标签 |
| **状态区** | 血条（独立）、蓝条（独立）、Buff/Debuff图标 |
| **技能栏** | 显示技能图标和当前解锁层级 |

### 2.2 稀有度视觉区分
| 稀有度 | 边框特效 |
|--------|----------|
| 金卡 | 金色边框 + 角色光环粒子特效 |
| 紫卡 | 紫色边框 + 流光边框特效 |
| 蓝卡 | 蓝色边框 + 简单边框描边 |

### 2.3 战斗表现
**攻击流程**：
1. 攻击者卡牌轻微前移动画 + 亮起高光
2. 特效播放（普攻弹道/技能特效）
3. 受击者卡牌震动 + 闪红 + 伤害数字飘字
4. 血条/蓝条平滑过渡动画

**大招释放**：
- 卡牌立绘放大到屏幕中央
- 技能CG/立绘高亮
- 播放华丽技能特效
- 结束后卡牌归位

## 三、独立血条战斗系统

### 3.1 六大职业定位

| 职业 | 血量 | 攻击 | 速度 | 核心功能 | 目标优先级 |
|------|------|------|------|----------|------------|
| **坦克** | ★★★★★ | ★★☆☆☆ | ★☆☆☆☆ | 承伤、保护队友 | 优先攻击敌方前排 / 嘲讽技能 |
| **战士** | ★★★★☆ | ★★★☆☆ | ★★☆☆☆ | 前排输出、持续作战 | 优先攻击敌方前排 |
| **刺客** | ★★☆☆☆ | ★★★★★ | ★★★★★ | 爆发、切后排 | 优先攻击敌方后排脆皮 |
| **法师** | ★★☆☆☆ | ★★★★☆ | ★★☆☆☆ | AOE伤害、控制 | 优先攻击血量最多的敌人（溅射） |
| **射手** | ★★☆☆☆ | ★★★★★ | ★★★★☆ | 持续高输出、点杀 | 优先攻击血量最少的敌人（补刀） |
| **辅助** | ★★★☆☆ | ★☆☆☆☆ | ★★☆☆☆ | 治疗、增益、回蓝 | 优先治疗血量最少的友方 |

### 3.2 战斗流程
```
1. 双方12个角色按速度排序，形成行动队列
2. 轮到某角色行动时：
   - 根据职业定位自动选择目标（AI判定）
   - 执行普攻 → 造成伤害 + 回复自身蓝条
   - 蓝条满时自动释放大招 → 消耗全部蓝量
3. 角色血量归零时死亡，从战斗队列移除
4. 一方所有角色死亡，战斗结束
```

### 3.3 AI目标选择逻辑
| 职业 | AI逻辑 |
|------|--------|
| 坦克 | 优先攻击敌方前排，有嘲讽技能时优先使用 |
| 战士 | 优先攻击敌方前排 |
| 刺客 | 检测敌方后排血量最少的目标（法师、射手优先） |
| 法师 | 检测敌方密集目标释放AOE，优先攻击血量最多的敌人 |
| 射手 | 优先攻击血量最少的敌人（补刀机制） |
| 辅助 | 检测我方血量最少的目标进行治疗 |

## 四、美术资源需求

### 4.1 单角色资源
| 资源 | 数量 | 说明 |
|------|------|------|
| 立绘 | 1张 | 静态PNG，透明背景 |
| 卡牌框 | 3张 | 金/紫/蓝三档（可复用） |
| 技能图标 | 1-2个 | 角色专属技能图标 |
| 特效资源 | 若干 | 可复用通用特效库 |

### 4.2 成本对比
| 方案 | 单角色成本 | 说明 |
|------|------------|------|
| 3D建模 | 高 | 需要建模、骨骼绑定、动画、贴图 |
| 卡牌方案 | 低 | 只需1张立绘 + 通用特效（成本降低约70%） |

---

## 五、技术实现要点

### 5.1 小程序环境适配
- 使用Canvas或WebGL渲染卡牌
- 特效用粒子系统实现（可用LayaAir/Cocos引擎）
- 图片资源做WebP压缩降低包体积
- 卡牌动画用简单的Translate/Scale/Alpha即可

### 5.2 性能优化
- 卡牌立绘懒加载，只加载当前关卡通关的角色
- 特效资源池化，复用粒子对象
- 战斗动画可跳过（设置选项）

## 六、阵容搭配策略

### 6.1 推荐阵容
| 阵容类型 | 职业分布 | 特点 |
|----------|----------|------|
| 均衡阵容 | 坦克×1 + 战士×1 + 刺客×1 + 法师×1 + 射手×1 + 辅助×1 | 各方面均衡，适合新手 |
| 暴力输出 | 战士×2 + 刺客×2 + 射手×1 + 辅助×1 | 高爆发，快速结束战斗 |
| 防守反击 | 坦克×2 + 战士×2 + 辅助×1 + 射手×1 | 高生存，持久战优势 |
| 切后排流 | 刺客×3 + 射手×2 + 辅助×1 | 极端针对性，快速秒杀后排 |

### 6.2 职业克制关系
- **刺客** 克制 **法师、射手**（高爆发秒杀脆皮）
- **坦克** 克制 **刺客**（承伤保护后排）
- **法师** 克制 **战士**（AOE化解前排优势）
- **射手** 克制 **坦克**（持续输出打穿前排）
- **辅助** 无明显克制，但能显著提升团队续航
