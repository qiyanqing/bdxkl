# 地图调试工具设计方案

## 概述

打造一个完整的地图系统调试工具，用于验证大富翁地图路径是否符合设计规范（三大原则），支持可视化编辑、自动验证、配置化生成。

---

## 核心功能优先级

1. **路径编辑器** - 可视化创建/编辑路径
2. **自动验证系统** - 检测违规并高亮
3. **配置化生成** - 配置生成不同难度地图
4. **交互式调试** - 悬停显示详情

---

## 技术架构

### 架构类型
纯前端单页应用，使用 Canvas 进行地图渲染，配合 DOM 元素实现控制面板。

### 核心模块

| 模块 | 职责 |
|------|------|
| GridSystem | 网格坐标系统，管理格子位置、间距、对齐 |
| PathEditor | 路径编辑模块，处理格子的添加、删除、移动 |
| PathValidator | 路径验证器，检测三大原则违规 |
| MapRenderer | 地图渲染器，绘制格子、连接线、高亮效果 |
| UIController | 控制面板，处理用户交互和状态管理 |

### 数据结构

```javascript
// 格子数据
{
  id: number,           // 唯一标识
  x: number,            // X坐标（像素）
  y: number,            // Y坐标（像素）
  type: 'start' | 'normal',  // 格子类型
  prevId: number | null,     // 前一个格子ID
  nextId: number | null      // 后一个格子ID
}

// 地图数据
{
  grids: Grid[],        // 所有格子
  config: MapConfig     // 地图配置（难度、格子数等）
}

// 地图配置
{
  difficulty: '难度1-4' | '福利关',
  gridCount: 15 | 25 | 35 | 50 | 10,
  zigzagEdges: ['上', '右', '下'], // 哪些边有折线
  gridSize: 24,  // 格子像素尺寸
  gridGap: 4     // 格子间距
}
```

### 状态管理
使用简单的观察者模式，当路径数据变化时自动触发验证和重绘。

## 路径编辑器

### 三种编辑模式

| 模式 | 功能 |
|------|------|
| 添加模式 | 点击空白区域创建新格子，自动连接到上一个选中的格子 |
| 选择模式 | 点击选中，拖拽移动，显示连接关系 |
| 删除模式 | 点击删除，自动修复路径断裂 |

### 编辑操作

- **插入格子**：在两个格子之间的连线上点击，插入新格子
- **断开连接**：Alt+点击连接线，断开两个格子的连接
- **连接格子**：从一个格子拖拽到另一个格子，建立连接
- **设置起点**：双击格子设为起点（起点只能有一个）

### 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| A | 切换到添加模式 |
| S | 切换到选择模式 |
| D | 切换到删除模式 |
| Delete | 删除选中格子 |
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |
| Ctrl+S | 保存当前路径（导出JSON） |

### 视觉反馈

- 选中格子：金色边框 + 阴影效果
- 悬停格子：放大1.2倍
- 连接线：箭头指示方向（前驱→后继）
- 拖拽预览：显示半透明格子预览位置

## 自动验证系统

### 三大原则检测

**原则1：每个格子恰好2条边**
- 遍历所有格子，计算边对边相邻的格子数量
- 违规格子：红色高亮 + 显示实际边数
- 错误提示：`格子X有N条边（应为2）`

**原则2：禁止对角线连接**
- 检查任意两个格子是否满足 `|Δx| = step 且 |Δy| = step`
- 违规格子：橙色高亮 + 绘制对角线虚线
- 错误提示：`格子X与格子Y存在对角线连接`

**原则3：最少3条边有Z字折线**
- 检测每条边（上/右/下/左）的格子是否只沿直线排列
- 折线判定：某条边的格子Y坐标（上下边）或X坐标（左右边）是否发生变化
- 统计结果：显示有几条边有折线

### 验证面板UI

- 左侧显示验证状态：✓全部通过 / ✗发现问题
- 违规格子列表：点击跳转到对应格子位置
- 折线统计：可视化显示4条边的折线情况

### 实时验证

- 编辑操作后立即触发验证
- 轻量级验证（仅检查当前编辑格子）：编辑时
- 完整验证（检查所有格子）：保存时/手动触发

### 导出验证报告

- 导出JSON格式，包含所有违规格子详情
- 支持导出为markdown格式的可读报告

## 配置化生成

### 生成算法

基于配置自动生成符合规范的路径：
- 随机化Z字折线的具体位置和形状
- 保证起点位置固定在左上角
- 确保生成结果100%符合三大原则

### 一键测试

- 快速生成5种难度的地图
- 批量验证所有生成的地图
- 导出测试报告

---

## 交互式调试

### 悬停信息面板

- 格子编号、坐标
- 前驱/后继格子编号
- 是否违反原则（逐项显示）
- 所在边（上/右/下/左）

### 调试辅助线

- 显示网格参考线（辅助对齐）
- 显示格子间距（step标注）
- 高亮所有边对边相邻的格子
- 高亮所有对角线相邻的格子（警告）

### 路径预览

- 输入起点和骰子点数，预览移动路径
- 动画演示移动过程
- 显示最终到达的格子
