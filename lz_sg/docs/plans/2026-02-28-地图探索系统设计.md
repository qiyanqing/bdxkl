# 地图探索系统设计文档

**创建日期**：2026-02-28
**设计版本**：标准版本 v1.0

---

## 一、设计目标

实现大富翁风格的地图探索系统，作为战斗系统前置的关卡探索层。

**核心特性**：
- 环形地图，掷骰子转圈前进
- 多种格子类型（战斗/商店/buff/事件/休息/骰子）
- 强制战斗机制防止避战
- 骰子道具增加策略性
- 可配置的关卡模板

---

## 二、核心架构

### 2.1 模块结构

```
js/map/
├── MapScene.js          # 地图场景主类
├── MapGenerator.js      # 地图生成器
├── PlayerController.js  # 玩家控制器
├── GridEventSystem.js   # 格子事件系统
└── data/
    └── level-config.js  # 关卡配置模板
```

### 2.2 核心类设计

**MapScene** - 地图场景主类
- 职责：Canvas渲染、用户交互、场景管理
- 依赖：PlayerController、GridEventSystem

**MapGenerator** - 地图生成器
- 职责：根据配置生成环形格子路径
- 输入：totalGrids、gridTypes配置
- 输出：格子数组（带位置、类型、索引）

**PlayerController** - 玩家控制器
- 职责：管理位置、移动动画、骰子投掷
- 状态：当前位置、剩余骰子、道具栏

**GridEventSystem** - 格子事件系统
- 职责：处理各种格子类型的触发逻辑
- 与战斗系统通过页面跳转通信

### 4.2 2.5D格子渲染

- 格子形状：菱形，营造透视感
- 格子尺寸：宽80px，高60px（压缩Y轴）
- 格子间距：水平10px，垂直5px

4. 棋子逐格移动（每格200ms）

## 五、格子事件系统

### 5.1 格子类型实现

| 格子类型 | 触发逻辑 | UI反馈 |
|---------|---------|--------|
| 普通战斗 | 直接进入战斗场景 | 对战图标晃动 |
| 精英战斗 | 确认弹窗后进入 | 红色警告特效 |
| 商店 | 弹出商店面板购买 | 金币图标闪烁 |
| buff格 | 随机赋予临时buff | 光柱从天降 |
| 事件格 | 弹出事件，两选项 | 问号图标旋转 |
| 休息格 | 回复30%血量 | 绿色治疗波纹 |
| 骰子格 | 随机获得道具 | 道具飞入道具栏 |

### 5.2 强制战斗机制

- 累计投掷骰子数达到间隔值时触发
- 显示提示："已探索够深，强敌出现！"
- 战斗结束后继续当前移动

### 5.3 与战斗系统衔接

```javascript
triggerBattle(enemyType) {
  const mapState = this.getCurrentState();
  wx.navigateTo({
    url: `/pages/battle/battle?enemyType=${enemyType}`,
    events: {
      onBattleEnd: (result) => {
        if (result === 'win') {
          this.showRewardPanel();
        }
        this.restoreMapState(mapState);
      }
    }
  });
}
```

## 九、技术要点

### 9.1 2.5D坐标转换

```javascript
// 将网格坐标转换为2.5D屏幕坐标
function toScreen2D5(gridX, gridY) {
  const offsetX = (gridX - gridY) * (tileWidth / 2);
  const offsetY = (gridX + gridY) * (tileHeight / 2);
  return {
    x: centerX + offsetX,
    y: centerY + offsetY
  };
}
```

### 9.2 环形路径生成

```javascript
// 生成环形不规则路径
function generateRingPath(totalGrids) {
  const path = [];
  const layers = 3; // 3层环形
  const gridsPerLayer = Math.ceil(totalGrids / layers);

  for (let layer = 0; layer < layers; layer++) {
    const radius = baseRadius + layer * radiusStep;
    for (let i = 0; i < gridsPerLayer; i++) {
      const angle = (i / gridsPerLayer) * Math.PI * 2;
      path.push({
        x: Math.cos(angle) * radius,
        y: Math.sin(angle) * radius * 0.6 // 压缩Y轴
      });
    }
  }

  return path;
}
```
