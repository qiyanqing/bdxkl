# 发泄小游戏设计文档

**创建日期**: 2026-01-30
**项目状态**: 设计阶段
**技术栈**: Cocos Creator + TypeScript + 微信云开发

---

## 1. 项目概述

### 1.1 产品定位
一款微信小游戏，主打情绪发泄和压力释放。用户可以选择预设的卡通角色，通过付费操作对其进行各种攻击动作（扇巴掌、踹一脚、推倒等），获得情绪宣泄的满足感。

### 1.2 目标用户
- 职场人群（发泄工作压力）
- 情感宣泄人群（分手、失恋等负面情绪）
- 纯娱乐用户（图个乐子）
- 特定场景用户（节日整蛊等）

### 1.3 核心价值
- 提供安全、私密的发泄渠道
- 卡通风格降低暴力感，增加娱乐性
- 丰富的反馈机制增强解压效果
- 分层付费满足不同用户需求

## 2. 核心功能设计

### 2.1 预设角色库（MVP版本）
第一版本开发 **2-3个** 预设角色，后续迭代扩展：
- **老板角色** - 西装革履、表情严肃、贱兮兮的眼神
- **前任角色** - 根据性别可选男性/女性版本
- **讨厌同事** - 戴眼镜、滑稽表情

**角色设计规范**：
- 头身比 1:2 或 1:3（头大身小，参考光头强风格）
- 丑萌搞怪风格，刻意设计得欠揍
- 表情夸张丰富，增加攻击欲望
- 每个角色至少包含：待机动画、受击动画、特殊动作动画

### 2.2 攻击动作系统

#### 基础动作（免费 + 代币）
| 动作 | 描述 | 消耗 |
|------|------|------|
| 扇巴掌 | 手掌挥击，脸被打歪 | 免费/代币 |
| 踹一脚 | 脚踢，角色后退 | 免费/代币 |
| 推倒 | 用力推，角色倒地 | 免费/代币 |
| 跪下忏悔 | 强制跪下，低头忏悔 | 高级动作 |
| 踩踏 | 用脚踩角色头部 | 高级动作 |

**架构设计**：
- 动作数据结构化，便于扩展新动作
- 每个动作配置：动画、音效、特效、消耗、是否高级
- 预留"添加新动作"的接口

### 2.3 反馈系统

#### 视觉反馈
- **角色动画**：根据攻击类型播放对应受击动画（后退、摇晃、倒地等）
- **表情变化**：攻击时角色表情变化（痛苦、惊恐、流泪等）
- **打击特效**：攻击点出现星星/波纹效果
- **屏幕震动**：攻击时屏幕轻微震动增强冲击感
- **反馈词飘出**："爽！""解气！""舒服！"等词随机飘出
- **攻击轨迹线**：显示攻击动作的轨迹
- **环境变化**：背景颜色/速度线随攻击变化

#### 听觉反馈
不同动作对应不同音效：
- 扇巴掌："啪！" + "哎哟！"
- 踹一脚："咚！" + "哼哧..."
- 推倒："哗啦！" + "啊啊！"
- 跪下："扑通！" + 低声哭泣
- 踩踏："啪嗒！" + 惨叫

## 3. 付费体系设计

### 3.1 用户分层

| 用户类型 | 免费动作 | 高级动作 | 获取方式 |
|---------|---------|---------|---------|
| 普通用户 | 有限次 | ❌ | 无 |
| 看广告用户 | 5次/广告 | ❌ | 观看广告（后续接入） |
| VIP用户 | 每日额度 | 每日额度 | VIP订阅（后续接入） |
| 代币购买 | 按次数 | ✅ | 购买怒气值 |

### 3.2 代币系统（怒气值）

#### 充值档位
| 档位 | 价格 | 获得怒气值 | 赠送 |
|------|------|-----------|------|
| 小礼包 | ¥1 | 100 怒气值 | - |
| 中礼包 | ¥6 | 600 怒气值 | +50 赠送 |
| 大礼包 | ¥18 | 2000 怒气值 | +200 赠送 |
| 超值礼包 | ¥68 | 8000 怒气值 | +1000 赠送 |

#### 动作消耗
| 动作类型 | 免费用户 | 代币用户 |
|---------|---------|---------|
| 扇巴掌 | 每日3次 | 10 怒气值 |
| 踹一脚 | 每日2次 | 15 怒气值 |
| 推倒 | 每日1次 | 20 怒气值 |
| 跪下忏悔 | - | 50 怒气值 |
| 踩踏 | - | 30 怒气值 |

### 3.3 开发阶段

**第一阶段（MVP）**：
- ✅ 基础免费动作（每日限额）
- ✅ 代币购买怒气值
- ✅ 高级动作代币消费

**第二阶段（后续迭代）**：
- 📋 看广告获取免费次数
- 📋 VIP订阅系统
  - 月卡 ¥18/月：每日送20次免费动作 + 5次高级动作
  - 季卡 ¥48/季：每日送30次免费动作 + 10次高级动作
  - 年卡 ¥168/年：每日送50次免费动作 + 20次高级动作

### 3.4 配置化设计

**所有数值均支持云端配置热更新，无需发版**：

```typescript
// 云数据库配置表结构
interface GameConfig {
  // 充值档位配置
  rechargePackages: {
    id: string;
    name: string;
    price: number;        // 价格（分）
    coins: number;        // 获得怒气值
    bonus: number;        // 赠送怒气值
  }[];

  // 动作消耗配置
  actionCosts: {
    actionId: string;
    freeDailyLimit: number;  // 免费用户每日次数
    coinCost: number;        // 代币消耗
    isPremium: boolean;      // 是否为高级动作
  }[];

  // VIP配置
  vipPackages: {
    id: string;
    name: string;
    price: number;
    duration: number;        // 天数
    freeDailyActions: number;
    premiumDailyActions: number;
  }[];

  // 广告配置
  adReward: {
    videoFreeActions: number;  // 看广告获得免费次数
  };
}
```

**客户端启动时自动拉取最新配置，支持A/B测试和动态调价。**

### 3.5 支付安全

- 云函数处理支付回调，防止篡改
- 代币余额实时同步云端
- 支付失败自动回滚
- 异常订单监控机制

### 4.3 核心系统设计

#### 角色控制器
```typescript
class CharacterController {
  // 角色状态：idle, hit, kneeling, fallen
  private state: CharacterState;

  // 播放动作动画
  playAction(actionId: string): void;

  // 播放受击动画
  playHitAnimation(hitType: string): void;

  // 表情切换
  setExpression(expression: string): void;
}
```

#### 动作管理器
```typescript
class ActionManager {
  // 执行动作（检查消耗、播放动画、扣费）
  async executeAction(actionId: string): Promise<boolean>;

  // 检查是否可执行
  canExecute(actionId: string): boolean;

  // 从云端拉取动作配置
  async fetchActionConfig(): Promise<void>;
}
```

#### 反馈管理器
```typescript
class EffectManager {
  // 播放打击特效
  playHitEffect(position: Vec3): void;

  // 飘出反馈词
  showFeedbackText(text: string): void;

  // 屏幕震动
  screenShake(intensity: number): void;

  // 环境变化
  changeBackground(color: Color): void;
}
```

### 4.4 云开发架构

#### 数据库设计
```javascript
// users 集合
{
  _openid: string,

// game_logs 集合
{
  _openid: string,
```

- `consumeCoins` - 扣除怒气值
