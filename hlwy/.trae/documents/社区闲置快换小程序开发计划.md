# 社区闲置快换小程序开发计划

## 一、项目初始化
1.  **初始化微信小程序项目**
   - 使用微信开发者工具创建小程序项目
   - 配置项目基本信息（AppID、名称、目录等）
   - 初始化Git仓库

2.  **技术栈选择**
   - 前端：原生微信小程序开发框架（WXML/WXSS/JS）
   - 后端：Node.js + Express + MongoDB
   - 云服务：腾讯云（云服务器、云数据库）
   - API：微信登录API、腾讯地图API、微信支付API

## 二、核心功能模块划分

### （一）用户认证与地址管理模块
1.  **微信一键登录**
   - 集成微信登录API
   - 获取用户基本信息（头像、昵称）
   - 生成用户唯一标识

2.  **标准化双地址管理**
   - 小区地址：调用腾讯地图API获取10公里内小区POI列表
   - 公司地址：先选择园区POI，再联想推荐企业列表
   - 地址切换与缓存机制
   - 30天冷却期与修改记录

### （二）闲置发布与展示模块
1.  **闲置发布功能**
   - 多图上传与预览
   - 标题、描述、分类、状态、价格设置
   - 地址展示范围选择（仅小区/仅公司/双地址）
   - 场景标签自动生成

2.  **首页列表与距离计算**
   - 按最新/最近排序
   - 调用腾讯地图API计算距离范围
   - 距离范围标签显示（500米内、1-3公里等）
   - 物品卡片展示

### （三）搜索与筛选模块
1.  **关键词搜索**
2.  **多条件筛选**
   - 场景筛选（居民/商业园区）
   - 分类筛选
   - 价格区间筛选
   - 新旧程度筛选
3.  **场景联动逻辑**

### （四）沟通撮合与管理模块
1.  **内置聊天系统**
   - 文字与图片发送
   - 关键词过滤（隐私信息、违规广告）
   - 聊天记录保存

2.  **用户中心**
   - 我的发布/收藏/成交记录
   - 地址管理入口
   - 发布内容修改与下架功能

### （五）积分与增值服务模块
1.  **积分体系**
   - 积分获取（签到、发布、成交、举报）
   - 积分消耗（抵扣置顶费用）

2.  **置顶增值服务**
   - 置顶套餐设置
   - 微信支付集成
   - 置顶内容展示逻辑

## 三、开发优先级

### 第一优先级（MVP核心闭环）
1.  微信登录功能
2.  标准化双地址管理（含冷却期）
3.  闲置发布与展示（含距离范围标签）
4.  搜索筛选（场景联动）
5.  内置聊天（含关键词过滤）
6.  基础举报与处理后台
7.  微信官方广告组件接入

### 第二优先级（促活与营收闭环）
1.  积分体系（基础获取与抵扣逻辑）
2.  置顶增值服务（支付流程）
3.  简易数据看板（日活、发布量、成交率）

### 第三优先级（增长优化）
1.  场景化标签与专场运营
2.  邀请裂变机制
3.  互评与信任体系
4.  积分体系扩展（荣誉标识、刷新功能）

## 四、具体实现步骤

### 阶段一：项目基础架构搭建（1-2天）
1.  初始化微信小程序项目
2.  搭建Node.js后端服务
3.  配置MongoDB数据库
4.  集成微信登录API

### 阶段二：核心功能开发（7-10天）
1.  双地址管理功能开发
2.  闲置发布功能开发
3.  首页列表与距离计算功能开发
4.  搜索筛选功能开发
5.  内置聊天功能开发

### 阶段三：辅助功能与优化（5-7天）
1.  积分体系开发
2.  置顶增值服务开发
3.  举报与处理后台开发
4.  微信广告组件接入
5.  数据看板开发

### 阶段四：测试与上线（3-5天）
1.  功能测试与bug修复
2.  性能优化
3.  安全审核
4.  小程序上线发布

## 六、关键API集成
1.  **微信登录API**：获取用户信息与会话密钥
2.  **腾讯地图API**：获取POI列表、计算距离
3.  **微信支付API**：实现置顶服务支付
4.  **微信消息推送API**：聊天消息通知

## 七、风控与安全措施
1.  **内容安全审核**：违禁品清单、关键词过滤
2.  **用户纠纷预防**：强提示与免责声明
3.  **数据安全与隐私**：最小化原则、定期备份
4.  **举报处理机制**：24小时内手动处理，阶梯处罚

## 八、运营准备
1.  **初始内容填充**：发布10-20条真实闲置物品
2.  **用户协议与隐私政策**：完善法律文件
3.  **举报与客服入口**：设置清晰的举报渠道
4.  **数据统计与分析**：配置基础数据看板
