# 发泄情绪小游戏

一款微信小程序端的情绪发泄游戏，用户可以创建自定义虚拟形象（上传真实照片或选择预制卡通角色），通过多种攻击方式进行发泄。

## 功能特性

- **虚拟形象系统**
  - 支持上传真实照片，AI自动抠图
  - 支持选择预制卡通角色
  - 可创建多个形象，独立统计
  
- **攻击技能系统**
  - 物理攻击：扇耳手、拳打、飞踢
  - 道具攻击：扔鸡蛋、泼水、扔鞋子
  - 魔法攻击：火球术、雷击、冰冻
  - 言语攻击：弹幕吐槽、语音喊话
  
- **受击反馈**
  - Spine 2D骨骼动画
  - 震动反馈
  - 伤害飘字效果
  - 技能冷却系统
  
- **分享统计**
  - 实时统计攻击数据
  - 生成分享海报
  - 里程碑触发分享

## 技术栈

- **前端**: 微信小程序原生 + Canvas
- **动画**: Spine 2D骨骼动画
- **AI处理**: 腾讯云/阿里云人像抠图API
- **后端**: 微信云开发（云函数+云存储+云数据库）

## 快速开始

### 前置要求

- 微信开发者工具
- 微信小程序开发权限
- 云开发环境

### 安装步骤

1. 克隆项目
```bash
git clone <repository-url>
cd venting-game
```

2. 安装依赖
```bash
npm install
```

3. 配置云开发

在 `app.js` 中配置云环境ID：
```javascript
wx.cloud.init({
  env: 'your-env-id', // 替换为实际环境ID
  traceUser: true
})
```

4. 上传云函数

在微信开发者工具中：
- 右键点击 `cloudfunctions` 文件夹
- 选择"上传并部署：云端安装依赖"

5. 配置人像抠图API

编辑 `cloudfunctions/removeBackground/index.js`：
- 申请腾讯云人像分割服务
- 配置 `SecretId` 和 `SecretKey`
- 在云开发控制台设置环境变量

### 运行项目

1. 打开微信开发者工具
2. 导入项目目录
3. 点击"编译"按钮

## 配置说明

### 云函数配置

#### login
自动获取用户openid，无需额外配置。

#### removeBackground
需要配置腾讯云API密钥：

1. 访问 [腾讯云控制台](https://console.cloud.tencent.com/)
2. 开通"人像分割"服务
3. 获取密钥后配置环境变量：
   - `TENCENT_SECRET_ID`
   - `TENCENT_SECRET_KEY`

### 游戏配置

编辑 `config/game.config.js`：
- 调整技能伤害和CD
- 配置分享触发阈值
- 添加卡通角色

## 注意事项

### 微信审核

- 避免使用真实暴力元素
- 卡通化处理所有视觉效果
- 不使用真实惨叫音效
- 伤害数字使用卡通字体

### 成本控制

- 人像抠图约 0.01-0.05元/次
- 建议设置每日免费额度
- 超出后降级到本地处理
