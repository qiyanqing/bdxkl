## 1. 工具下载与安装

### 1.1 DragonBounds 下载

**官方下载地址：**
- 官网：https://dragonbones.org
- 直接下载：https://dragonbones.org/downloads.html

**选择版本：**
- Windows：下载 `DragonBones Pro x.x.x.exe`
- Mac：下载 `DragonBones Pro x.x.x.dmg`

**当前最新版本：** 5.6（可随时间更新）

**国内镜像（如果官网慢）：**
- 搜索"DragonBounds 下载"
- 或访问：https://www.pc6.com/softview/SoftLink_2.html

### 1.2 图片处理工具（必需）

**需要准备以下任一工具：**

#### 选项A：Photoshop（付费）
- 下载：https://www.adobe.com/products/photoshop
- 需要：分层处理图片

#### 选项B：Photopea（免费在线）
- 访问：https://www.photopea.com
- 功能：类似 PS，免费使用
- 无需安装

#### 选项C：GIMP（免费开源）
- 下载：https://www.gimp.org
- 功能：类似 PS，完全免费
- 需要安装

#### 选项D：美图秀秀（最简单）
- 下载：手机应用商店搜索"美图秀秀电脑版"
- 功能：抠图简单
- 适合新手

### 1.3 安装 DragonBones

**Windows：**
```
1. 下载 .exe 安装文件
2. 双击运行
3. 选择安装路径（建议：D:\Programs\DragonBones\）
4. 点击"安装"
5. 完成后打开 DragonBones Pro
```

**Mac：**
```
1. 下载 .dmg 文件
2. 双击打开
3. 拖拽到"应用程序"文件夹
4. 在启动台找到 DragonBones Pro 并打开
```

## 2. AI 生成角色素材提示词

### 2.1 提示词使用指南

**推荐 AI 工具：**
- **Midjourney**：效果最好，需要订阅（$10-35/月）
- **Stable Diffusion**：免费，需要本地部署
- **文心一格**：百度出品，免费好用

### 2.2 角色分层素材提示词

**通用说明：**
- 每个角色需要生成 **分层素材**
- 分层结构：头部、身体、左臂、右臂、左腿、右腿
- 每一层单独生成，背景透明
- 图片尺寸：512x512 或 1024x1024

## 3. DragonBones 基础教程

### 3.1 界面介绍

打开 DragonBones Pro 后，你会看到：

**菜单栏：**
- File（文件）
- Edit（编辑）
- View（视图）
- Help（帮助）

**主要区域：**
- **左侧**：项目树（Project Tree）
- **中间**：视图/编辑区域
- **右侧**：属性面板（Properties）

### 3.2 核心概念

**骨骼：**
- 角色的"骨架"
- 控制图片如何移动、旋转、缩放
- 例如：头骨、身体骨、手臂骨等

**插槽：**
- 附着在骨骼上的图片
- 一个骨骼可以挂载多张图片
- 用于显示角色的外观

**动画：**
- 骨骼随时间变化的运动轨迹
- 包括：位置、旋转、缩放、透明度等

## 4. 制作完整动画流程

### 4.1 创建新项目

**步骤：**
```
1. 打开 DragonBones Pro
2. 点击 File → New Project
3. 命名项目：male_boss（啰嗦上司）
4. 选择保存路径
5. 设置：
   - Scale: 0.5（缩放比例）
   - 代码输出路径：自动生成
6. 点击"Save"
```

### 4.2 导入分层图片

**步骤：**
```
1. 点击 File → Import Image
2. 选择准备好的 PNG 图片
3. 按顺序导入：
   - head.png（头部）
   - body.png（身体）
   - arm_l.png（左臂）
   - arm_r.png（右臂）
   - leg_l.png（左腿）
   - leg_r.png（右腿）
```

**导入后效果：**
- 左侧 Project Tree 会显示所有导入的图片
- 中间视图会显示所有图片叠在一起

### 4.3 创建骨骼

**创建根骨骼：**
```
1. 点击左侧"Create Bone"按钮（或按快捷键 N）
2. 在视图中心点击创建根骨骼（命名为 root）
3. 根骨骼是所有其他骨骼的父节点
```

**创建子骨骼：**
```
1. 选中根骨骼 root
2. 点击"Create Bone"
3. 在相应位置创建子骨骼：
   - head（头部骨骼，放在头的位置）
   - body（身体骨骼，放在身体中心）
   - arm_l（左臂骨骼）
   - arm_r（右臂骨骼）
   - leg_l（左腿骨骼）
   - leg_r（右腿骨骼）
```

**骨骼层级结构：**
```
root（根）
├── head（头部）
├── body（身体）
├── arm_l（左臂）
├── arm_r（右臂）
├── leg_l（左腿）
└── leg_r（右腿）
```

### 4.4 绑定图片到骨骼

**绑定头部：**
```
1. 选中 head 骨骼
2. 在右侧 Properties 面板找到"Images"区域
3. 点击"+"按钮，添加 head.png
4. 图片会自动附在骨骼上
5. 调整图片的位置和旋转，使其与骨骼对齐
```

**绑定其他部位：**
```
重复以上步骤，分别绑定：
- body.png → body 骨骼
- arm_l.png → arm_l 骨骼
- arm_r.png → arm_r 骨骼
- leg_l.png → leg_l 骨骼
- leg_r.png → leg_r 骨骼
```

**关键提示：**
- 确保图片的"旋转中心"（旋转轴心）在正确的位置
- 手臂的轴心应该在肩膀位置
- 腿的轴心应该在臀部位置

### 4.5 创建待机动画

**设置待机动画：**
```
1. 点击底部的"Dopesheet"标签页
2. 默认会有"setup"动画（这是待机姿势）
3. 在时间轴的第0帧，调整各骨骼到自然站立姿势

待机姿势参考：
- head: 轻微向下
- body: 直立
- arms: 自然下垂
- legs: 并拢站立
```

**添加动画帧：**
```
1. 点击时间轴上的第10帧
2. 调整各骨骼：
   - head: 向下移动5像素，模拟呼吸
   - body: 向下移动3像素
3. 点击第20帧
4. 恢复到原始姿势
```

**设置循环：**
```
1. 点击第20帧
2. 在右侧属性找到"Loop"
3. 勾选"Loop"复选框
4. 设置播放速度：默认0.5秒（20帧）
```

### 4.6 创建受击动画

**新建动画轨道：**
```
1. 在 Dopesheet 面板，点击"+"按钮
2. 创建新动画，命名为"hit"
3. 点击 OK
```

**制作受击动画（3-5帧）：**

**第0帧（正常状态）：**
- 所有骨骼保持 setup 姿势

**第1帧（受到冲击）：**
- head: 向后旋转10度，向上移动10像素
- body: 向后旋转5度
- arms: 稍微张开

**第2帧（最大冲击）：**
- head: 向后旋转20度，向上移动20像素
- body: 向后旋转10度，向后移动10像素
- 所有四肢：轻微张开

**第3帧（开始恢复）：**
- head: 旋转减半，下降5像素
- body: 旋转减半，前移5像素

**第4帧（恢复原状）：**
- 所有骨骼回到 setup 姿势

**设置：**
- 总时长：约 0.3 秒
- 不循环（不勾选 Loop）

### 4.7 创建攻击动画

**新建动画：**
```
1. 创建新动画，命名为"attack"
```

**制作攻击动画（5-8帧）：**

**第0帧（准备）：**
- 所有骨骼在 setup 姿势
- arm_r（右臂）：向后抬起，准备出拳

**第1帧（蓄力）：**
- arm_r：继续向后抬起30度
- body：身体前倾10度
- head：向前看

**第2帧（出拳）：**
- arm_r：快速向前伸出，旋转45度
- body：身体前倾20度，向前移动15像素

**第3帧（命中）：**
- arm_r：到达最远点
- body: 前倾最大
- 整个角色向前移动20像素

**第4-5帧（收招）：**
- arm_r：收回，恢复原状
- body: 直立，后退回原位
- 整个角色退回原位

## 5. 导出与集成

### 5.1 导出动画

**步骤：**
```
1. 点击 File → Export
2. 选择导出格式：
   - Spine（推荐）或
   - JSON（也支持）
3. 设置导出路径
4. 点击"Export"
```

**导出后生成的文件：**
```
male_boss.json      # 骨骼数据文件
male_boss.atlas     # 图集文件
male_boss.png       # 纹理图片
```

### 5.2 文件放置到项目

**创建目录结构：**
```
venting-game/
└── assets/
    └── characters/
        ├── male_boss/
        │   ├── male_boss.json
        │   ├── male_boss.atlas
        │   └── male_boss.png
        ├── male_colleague/
        ├── male_tough_guy/
        ├── female_auntie/
        └── ...
```

**复制文件：**
1. 在项目根目录创建 `assets/characters/` 目录
2. 为每个角色创建子目录（如 `male_boss/`）
3. 将导出的3个文件复制到对应目录

## 6. 常见问题解决

### Q1: 导入图片后看不到

**解决：**
- 检查图片格式是否为 PNG
- 检查图片是否有透明背景
- 尝试刷新视图（View → Refresh）

### Q2: 骨骼移动但图片不动

**解决：**
- 检查图片是否正确绑定到骨骼
- 选中骨骼，在右侧 Properties 面板找到 Images
- 确认图片已添加

### Q3: 动画播放不流畅

**解决：**
- 减少帧数（关键帧之间插值自动处理）
- 调整播放速度
- 使用"Test Animation"按钮预览效果

### Q4: 导出的文件小程序无法使用

**解决：**
- 确保导出为 JSON 格式（不是二进制）
- 检查文件路径是否正确
- 我会帮你集成 Spine 运行库
